# Letta Consulting Portal

A responsive React + Vite + TypeScript starter for the Letta Consulting career guidance, psychological wellness and professional support portal.

## Getting started

```bash
npm install
npm run dev
```

## Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Project structure

- `src/components` reusable interface components
- `src/pages` page-level experiences
- `src/styles` global styling
- `public/assets` brand and media assets

The current homepage is a frontend foundation. Booking, authentication, portals and data persistence will be connected in later implementation phases.
